# Videos de Magic Power Travel

Aquí se guardan todos los videos para clientes: bienvenida, sorpresa, viajes a Disney, etc.

Cada video tiene **su propia carpeta**, con el formato `fecha-tipo-cliente`. Por ejemplo:

```
videos/
  2026-10-15-sorpresa-sofia/
    video.mp4   ← el video terminado, listo para mandar por WhatsApp
    notas.md    ← qué se pidió y cómo se hizo
```

Para encontrar un video: buscar la carpeta por fecha o por nombre del cliente.
